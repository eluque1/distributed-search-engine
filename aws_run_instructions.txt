our aws setup is: 

m6ilarge for the kvs coordinator
i3xlarge for the kvs worker
m6ilarge for the flame coordinator
c6i2xlarge for the flame worker
and a t3 micro for submitting

aws sync instructions: 

Go to AWS Console, Click your name (top right), Security credentials
Scroll down to "Access keys"
Click "Create access key"
Choose "Command Line Interface (CLI)"
Download the key

in terminal: 

aws configure

enter these: 
Access Key ID (from the key you just created)
Secret Access Key (from the key you just created)
Region: us-east-1 (or whatever region your bucket is in)
Output format: json

finally run this in terminal from root of repository to sync: 
aws s3 sync worker1/pt-crawl s3://555-project-crawl/pt-crawl
